# NeoStore v0.3.0 — Marketplace Phase 3

فروشگاه دیجیتال خودمیزبان، یک پله نزدیک‌تر به تجربهٔ مارکت‌پلیس‌های جدی.

این نسخه ظاهر فروشگاه، مدیریت مدیا، استوک ووچر و تحویل سفارش را کامل‌تر می‌کند — بدون دادهٔ فیک و بدون وابستگی به CDN خارجی.

---

## چه چیزی جدید است؟

### فروشگاه با حس مارکت‌پلیس
- صفحهٔ اصلی با نوار جستجو، نوار اعتماد، چیپ دسته‌ها با آیکون، و گرید محصولات ویژه
- الهام از اطلاعات‌معماری سایت‌های ووچر (نه کپی ظاهری برند)
- اگر کاتالوگ خالی باشد، empty state واقعی — بدون محصول جعلی

### طراحی صفحهٔ اصلی (Homepage CMS)
- مسیر Seller: **Homepage designer**
- تنظیمات روی `StoreProfile` همان ورک‌اسپیس ذخیره می‌شود
- کنترل هیرو، بولت‌های اعتماد، نمایش دسته‌ها، و حالت Featured / All / انتخاب دستی

### آیکون‌های کاتالوگ
- پک SVG داخلی (~۵۰ آیکون مارکت‌پلیسی)
- در Categories یک picker بصری؛ مقدار در `Category.icon` ذخیره می‌شود
- همان آیکون‌ها در چیپ‌های استورفرانت دیده می‌شوند

### تصویر محصول + آپلود محلی
- آپلود امن JPEG / PNG / WebP (حداکثر ۵MB)
- ذخیره زیر مسیر `STORAGE_LOCAL_PATH`
- نمایش تصویر در کارت محصول، جزئیات، و لیست ادمین

### استخر ووچر و تحویل آنی
- مدیریت Inventory pools و چسباندن کدها (هر خط یک کد)
- محصول Instant به استخر وصل می‌شود؛ `stockCount` با کدهای آزاد همگام است
- بعد از پرداخت، کد رزرو و در entitlement تحویل داده می‌شود
- چک‌اوت اگر استوک خالی باشد متوقف می‌شود

### تحویل با تأخیر + ریفاند خودکار
- حالت Manual: بعد از تأیید پرداخت → Processing + مهلت SLA
- اگر فروشنده تا `deliverByAt` تحویل ندهد → وضعیت **Refunded** و اعتبار به کیف‌پول مشتری (`LedgerEntry` از نوع Refund)
- کرون داخلی + endpointهای `cron/sla-refund` و `cron/tick`

## تصاویر Docker

| سرویس | تگ پیشنهادی |
|--------|-------------|
| API | `ghcr.io/neoauroraproject/neostore-api:v0.3.0` |
| Storefront | `ghcr.io/neoauroraproject/neostore-storefront:v0.3.0` |
| Admin | `ghcr.io/neoauroraproject/neostore-admin:v0.3.0` |

تگ‌های `0.3.0` و `0.3` هم منتشر می‌شوند. برای آخرین بیلد پایدار می‌توانید `latest` بمانید.

### به‌روزرسانی سرور

```bash
cd /opt/neostore
# پین به این ریلیز (پیشنهادی)
sed -i 's/^NEOSTORE_VERSION=.*/NEOSTORE_VERSION=v0.3.0/' .env
docker compose pull && docker compose up -d
```

اسکیما با `prisma db push` هنگام استارت API اعمال می‌شود.
