# NeoStore v0.4.1 — Commercial updates + API boot fix

## Fixes
- API entrypoint uses `prisma db push --accept-data-loss` so unique-index upgrades no longer crash-loop the API (storefront 502 / login JSON errors).

## Commercial update channels
1. **Super Admin → Platform → System updates** — Check GitHub releases, queue deploy to a tag/`latest`.
2. **Host CLI** — `sudo bash /opt/neostore/install/neostore.sh update` or `... update v0.4.1`.
3. **Updater sidecar** — watches `/data/storage/update-request.json`, pulls GHCR images, recreates the stack. API remigrates DB on boot.

## Deploy
```bash
NEOSTORE_VERSION=v0.4.1
# or:
sudo bash /opt/neostore/install/neostore.sh update v0.4.1
```
