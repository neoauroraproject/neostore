# NeoStore v0.4.0 — Plugin Host + Marketplace UX

زیرساخت پلاگین/قالب شبیه وردپرس، فروشگاه تمیزتر، ورود مشتری/فروشنده، درگاه‌های پلاگینی، SMTP، و پورتال مشتری.

## Highlights

### Plugin & Theme Manager
- نصب / فعال / تنظیمات / غیرفعال (داده می‌ماند) / حذف
- Contributions: menus, settings, webhooks, theme sections
- Official: Cryptomus, NOWPayments, Marketplace theme
- Audit log + encrypted secrets

### Storefront
- بدون لینک Admin روی هوم
- Log in / Register
- سرچ بازشونده در هدر
- تم marketplace + optional crypto-dark

### Commerce & portal
- دارایی‌های کریپتو سطح پلتفرم
- تیکت مشتری/فروشنده → سوپرادمین
- SMTP قابل تنظیم + تست ایمیل
- Docker image prune بعد از Update

## Deploy

```bash
NEOSTORE_VERSION=v0.4.0
docker compose pull && docker compose up -d
```

Images: `ghcr.io/neoauroraproject/neostore-{api,storefront,admin}:v0.4.0`
